## Detailed Maps 1.3.0

Charcoal/Color map styles via ModSettings, with on-demand loading from sidecar zip packs (no giant embedded DLL).

Includes updated HubRegion charcoal and color maps.

### Install
1. MelonLoader + [ModSettings](https://github.com/zeobviouslyfakeacc/ModSettings/releases) in `Mods\`
2. Copy into `Mods\`:
   - `DetailedMaps.dll`
   - `DetailedMaps.Charcoal.zip` (required)
   - `DetailedMaps.Color.zip` (optional — needed for Color style)
3. Options → Mod Settings → **Detailed Maps** → Charcoal or Color
